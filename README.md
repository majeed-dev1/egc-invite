# دعوة نادي الألعاب الإلكترونية

صفحة دعوة تفاعلية لورشة «من لاعب إلى صانع ألعاب». يقفز الزائر بشخصية بكسل على أربع منصات، ثم تخطفها مركبة فضائية وتظهر له الدعوة بتفاصيل الفعالية. عند القبول تنتقل الصفحة إلى تأكيد الحضور مع بطاقة دعوة وزر إضافة للتقويم.

المشروع ملفات ثابتة بدون مكتبات ولا خطوة بناء، وكل الرسم بالكود على `canvas`. الاعتماد الخارجي الوحيد هو خطّا Google Fonts (`Handjet` و`IBM Plex Sans Arabic`)؛ بدون إنترنت تعمل الصفحة بخط النظام.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل خادماً محلياً من مجلد المشروع:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

ثم افتح `http://localhost:5173/?to=أحمد`.

## رابط مخصص لكل مدعو

افتح صفحة `links.html`، اكتب اسم المدعو واضغط «إتمام»، فيظهر رابط دعوة خاص باسمه مع أزرار للنسخ والفتح والإرسال عبر واتساب. الأسماء تُحفظ في متصفحك فقط حتى تمسحها.

الصفحة تبني الرابط من عنوانها هي، فافتحها من رابط الموقع المنشور لتحصل على روابط تعمل عند الجميع. إذا فتحتها من جهازك (`localhost` أو الملف مباشرة) فالروابط تعمل على جهازك فقط.

الرابط نفسه هو عنوان الموقع مع اسم المدعو، ويظهر الاسم في شاشة البداية والدعوة وبطاقة التأكيد:

```
https://your-site.example/?to=أحمد
```

## تفاصيل الفعالية

كل التفاصيل في الكائن `EVENT` أعلى `game.js`:

| الإعداد | وظيفته | القيمة الحالية |
| --- | --- | --- |
| `title` | اسم الفعالية | `ورشة «من لاعب إلى صانع ألعاب»` |
| `host` | الجهة الداعية | `نادي الألعاب الإلكترونية` |
| `day` / `date` / `time` | الموعد كما يظهر للمدعو | `الأحد` / `٢٩ نوفمبر` / `١١ ص – ٤ م` |
| `place` | المكان | `مسرح وادي مكة` |
| `start` / `end` | الموعد الفعلي لزر التقويم | `2026-11-29T11:00:00+03:00` إلى `16:00` |
| `mapUrl` | رابط الخريطة (اختياري) | فارغ |
| `registerUrl` | رابط نموذج التسجيل، يُظهر زر «سجّل في الورشة» في صفحة التأكيد | نموذج Google |

`day`/`date`/`time` نصوص للعرض و`start`/`end` للتقويم، فإذا تغيّر الموعد عدّل الاثنين معاً. وحدّث أيضاً وصف الصفحة في `index.html` (`description` و`og:description`).

### التسجيل

الصفحة بلا خادم، فشاشة «تم تأكيد حضورك» تظهر للزائر فقط. التسجيل الفعلي يتم في النموذج الموجود في `registerUrl`: يفتحه زر «سجّل في الورشة» في تبويب جديد. من يقبل الدعوة ولا يعبّئ النموذج لا يصل المنظّمَ عنه شيء.

إذا احتوى الرابط على `{name}` يُستبدل باسم المدعو، وهذا يفيد في تعبئة حقل الاسم مسبقاً في نماذج Google (`entry.رقم_الحقل={name}`).

## صفحة التأكيد

- عنوانها `#confirmed`، فزر الرجوع في المتصفح يعيد إلى الدعوة، وفتح الرابط مع `#confirmed` يعرض البطاقة مباشرة بدون لعب.
- «سجّل في الورشة» يفتح نموذج التسجيل.
- «أضف إلى التقويم» ينزّل ملف `workshop.ics` (تقويم Apple و Outlook وغيرها)، و«تقويم Google» يفتح نموذج الحدث جاهزاً.

## التحكم

- الفأرة أو اللمس: الزر السفلي أو أي مكان في المشهد.
- لوحة المفاتيح: المسافة أو السهم ↑.
- في الشريط العلوي زر لكتم الصوت وزر لملء الشاشة.

## النشر

يكفي رفع المجلد كما هو على GitHub Pages أو Netlify.

بعد النشر أضف صورة المعاينة في `index.html` برابط كامل حتى تظهر عند مشاركة الرابط:

```html
<meta property="og:image" content="https://your-site.example/preview.png">
```
